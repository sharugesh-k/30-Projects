# Netflix Data Analysis Project using Python & Pandas

## 📌 Project Overview

This project focuses on analyzing Netflix streaming data to uncover insights about content distribution, viewing patterns, and platform trends. The analysis explores metrics such as content types, release years, countries, ratings, and duration to provide comprehensive understanding of Netflix's content library.

This project demonstrates practical Data Analytics skills including:

* Exploratory Data Analysis (EDA)
* Data Visualization
* Statistical Analysis
* Data Aggregation
* Pattern Recognition
* Trend Analysis using Pandas

* CSV Dataset

## 📊 Analysis Focus Areas

### ✅ 1. Data Loading & Inspection

Imported the Netflix dataset using Pandas and performed initial exploration.

### ✅ 2. Data Cleaning & Preprocessing

* Standardized data types
* Removed duplicates
* Formatted categorical variables

### ✅ 3. Exploratory Data Analysis (EDA)

Analyzed key metrics including:

* Content distribution (Movies vs TV Shows)
* Release year trends
* Content rating distribution

* Duration analysis

### ✅ 4. Visualizations

Created comprehensive visualizations to understand:

* Distribution of content types
* Top countries producing content
* Content ratings popularity
* Release year trends

### ✅ 5. Statistical Insights

Generated meaningful statistics about:

* Average content duration
* Most common ratings
* Peak production years
* Geographic content distribution
